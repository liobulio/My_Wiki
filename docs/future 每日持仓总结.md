# future 每日持仓总结

> 暂存的日报格式设想（2026-10-09），**现在先不用**。启用前需要先和当前持仓、`brief/` 渲染器与
> daily-brief skill 对齐。

1. 今日最强信号：开头两句话总结当天最重要的市场变化，以及对我组合意味着什么、要不要动。
2. 组合直接相关信号：按持仓板块逐一梳理，包括美国科技/半导体（NVDA、MU、SOXX等）、纳指QQQ、BTC与加密相关股、A股/港股、黄金。每条都有数据和来源，并给出持有、加仓或减仓的建议。
3. QDII 溢价监控：每天跟踪纳指和标普 QDII 基金相对同类的溢价。平时只显示一行数据，只有出现明显的套利或风险窗口时，才会展开给出具体交易方案。
4. X关注流/ 社交面信号：从X（推特）上整理当天的市场讨论和情绪，未经核实的数字会单独标注。
5. 邻近机会：与现有持仓相关、可能改善风险收益的新标的或调仓思路。
6. 组合外信号：不直接影响持仓但值得留意的宏观、政策或行业动向。
7. 媒体聚焦：重点财经媒体和研报的核心观点摘要。
8. 本周前瞻：未来几天的关键事件日历，比如美联储、数据发布、财报、拍卖、停牌和假期等。
