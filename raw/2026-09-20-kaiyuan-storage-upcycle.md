1、 算力需求重构存储定位，供给刚性改写周期形态
1.1、 存储从配套走向瓶颈，存储层级沿带宽重构
数据量级的持续跃升与算力需求的快速释放，推动存储从配套支撑环节升级为
数字基建的核心支柱。在 5G、AI、AIOT 等新兴战略产业的快速发展带动下，信息
数据呈现爆发式增长，数据规模从原来的 GB、TB、PB 跃升至 EB、ZB 级，存储随
之从数据承载环节上升为制约算力释放的关键基础设施。中国信息通信研究院的数
据显示，截至 2026 年 6 月底，全国数据存力总规模达 2021EB，同比增长 11%，先
进存力占比提升至 32%，规模超过 640EB；工业和信息化部提出，到 2030 年先进存
力规模提升至 1700EB。半导体存储是当前存力的主要载体，历经半个多世纪演进已
形成以 DRAM 与 NAND 为主体的产品格局。
半导体存储也称为存储芯片，根据数据存储原理的不同，半导体存储器可以分
为随机存储器（RAM）和只读存储器（ROM）。RAM 可直接与 CPU 交换数据，
读写速度快，属易失性存储器，通常用作运行中程序的临时数据介质；按单元结构，
RAM 进一步分为静态随机存储器（SRAM）与动态随机存储器（DRAM），前者以
触发器保存数据、无需刷新，后者靠电容电荷保存、需定期刷新。ROM 只能读取事
先写入的数据，属非易失性存储器，用于存放固定程序与数据；按写入方式可分为
掩膜 ROM、PROM、EPROM、EEPROM 与闪存（Flash），其中 Flash 为当前主流，
并进一步划分为 NOR Flash 与 NAND Flash。

（一）SRAM
SRAM 即静态随机存储器，又称片上缓存，其数据由电路稳态维持，只要供电
便无需像 DRAM 那样周期性刷新。存储单元采用六晶体管结构：其中四只构成两个
交叉耦合的反相器，
即两只 PMOS 上拉管与两只 NMOS 下拉管首尾相接形成锁存器，
另两只 NMOS 为访问管，受字线控制。交叉耦合使两个反相器相互强化、形成正反
馈，两个存储节点必然维持一高一低，分别代表 1 与 0。之所以必须用有源电路而非
电容保存状态，是因为电荷会泄漏，状态必须由电路持续锁定。代价是每比特占用
六个晶体管，而 DRAM 每比特仅需一只晶体管加一个电容，单元面积显著更大、密
度更低。

SRAM 的优势与代价同源。其无需刷新即可保持数据，读写时序可预测，访问
延迟落在纳秒量级，先进节点下可低于 1 纳秒，快于 DRAM，且省去刷新带来的周
期性功耗；与 CMOS 逻辑工艺兼容，可同片集成，因而能紧贴运算单元构成片上缓
存与寄存器堆。代价在于面积与微缩难度：每比特六个晶体管使单元面积远大于
DRAM 的一晶体管一电容结构，单位成本高、集成度低，难以达到主存容量；单元
须兼顾读稳定与可写入，单元比例须大于 1.0 才能避免读扰动，工艺微缩后电压下降
与阈值波动使静态噪声容限退化，待机漏电逐代上升，低功耗优势仅在动态层面。
SRAM 最主要的应用是作为 CPU 的高速缓存，现代 CPU 的性能在很大程度上
取决于缓存系统的设计。为兼顾速度、容量与成本，CPU 缓存采用分级设计：L1 最
靠近 CPU 核心，速度最快、容量最小，通常为几十 KB，分为指令缓存与数据缓存；
L2 速度稍慢、容量更大，通常为几百 KB 至数 MB，作为 L1 与下一级间的缓冲；L3
由所有 CPU 核心共享，可达几十 MB，是访问主存前的最后一道防线。该分级使多
数访问能在最快层级命中，
平均访问延迟因而远低于直接访问主存。除 CPU 缓存外，
在 GPU 和 TPU 等专用 AI 芯片中，巨大的 SRAM 阵列被用来高效缓存输入数据、权
重和中间计算结果，以满足海量数据并行计算的需求。

（二）DRAM
DRAM 即动态随机存储器，又称系统主存，其数据以电容电荷存储，因电荷泄
漏而须周期性刷新。其存储单元仅由一个晶体管与一个电容构成，以电荷有无表示 1
与 0，是半导体存储器中结构最简的形态。简化带来的是密度与成本优势，相同面积
可容纳的比特数远多于 SRAM，单位容量成本也低得多，由此承担系统主存职能，
成为处理器直接寻址的工作内存。代价则源于电容的物理特性，介质并非理想绝缘，
电荷会随时间泄漏，单元必须由控制器周期性读取并重写；刷新既占用带宽，也使
其访问延迟显著高于 SRAM，存储层级中容量与速度的取舍由此落定。

DRAM 的产品谱系沿两条主线分化：通用主存序列以容量与成本为先，带宽优
先序列以位宽为先。前者的差异在功耗约束。DDR 面向计算机与服务器，采用同步
接口与双倍数据率；LPDDR 面向移动终端，把低功耗与小体积置于首位。后者共享
高带宽目标而集成路径不同。GDDR 在常规封装下堆高单引脚速率，以容忍较高延
迟换取带宽，服务于图形与显示；HBM 以硅通孔垂直堆叠多颗裸片、与 GPU 同封
装，以位宽而非频率取胜。四类共享同一单元结构，差异集中于接口标准、工作电
压与封装形态，而非存储机制本身，这也决定了它们之间不存在直接替代关系。

DDR 即双倍速率同步动态随机存储器，是 DRAM 面向通用计算的主存接口标
准，其在时钟的上升沿与下降沿各传输一次数据，同频下速率翻倍。它与 DRAM 并
非并列关系：DRAM 界定存储介质的单元结构与工作方式，DDR 则是在此之上由
JEDEC 制定的接口规范，覆盖引脚、时序、电压与命令协议。其中，存储数据的仍
是 DRAM 的电容单元阵列，DDR 规定的是这颗芯片与内存控制器间的通信方式。
多颗 DDR 颗粒焊装于模组板，并配以电压调节与系统管理元件，构成可插拔的内存
条。除双沿采样外，同步接口使读写与系统时钟对齐、可流水线化，进一步抬高了

HBM（High Bandwidth Memory，高带宽内存）是 3D DRAM 的代表性产品，
凭借高位宽特性突破单封装内存带宽瓶颈。HBM 以硅通孔将多层 DRAM 裸片垂直
堆叠，经硅中介层与 GPU 并排封装，以位宽而非频率换取带宽。实现依赖三项工艺：
其一为 TSV，在每层裸片刻出数千个微孔并填充铜，形成穿透硅片的垂直互连；其
二为微凸点，在 TSV 露头处以铜柱凸点完成层间键合与电连接；其三为硅中介层，
GPU 与 HBM 倒装焊接于同一硅片，经其表面的高密度铜互连交换信号。中介层与
芯片同为硅材质，热膨胀系数一致，可避免温度循环下的应力开裂，有机基板则难
以匹配该特性。台积电的 CoWoS 是 HBM 封装的事实标准，其产能在一定程度上直
接决定了全球 HBM 和 AI GPU 的供应量。

NAND 闪存是闪存的两大分支之一，其单元以串为单位串联共享位线，放弃随

4、 风险提示
大模型技术迭代不及预期风险。大模型技术迭代是推动产业能力边界拓展与下
游场景深化的核心驱动力，当前行业正处于多模态感知、复杂推理、智能体执行等
前沿技术的攻坚突破期，技术突破节奏、能力落地效果均存在一定不确定性。若后
续核心技术突破进度、模型能力提升幅度低于市场预期，无法有效支撑下游高价值
场景的深度适配与功能升级，可能导致产业落地节奏整体延后，行业成长进程存在
阶段性放缓的可能性。
AI 技术应用不及预期风险。下游场景规模化渗透是大模型产业价值兑现的核心
支撑，当前大模型正从技术概念验证期向垂直行业规模化应用期过渡，落地进度受
行业数字化基础、客户付费意愿、投入产出比验证等多重因素共同制约。若后续垂
直行业适配进度、企业付费转化节奏不及市场预期，产业商业价值的兑现周期可能
有所拉长，行业长期成长动能的释放节奏存在一定波动可能。
相关政策不及预期风险。大模型产业发展高度依赖政策环境的引导规范与配套
支持，当前人工智能领域处于快速发展阶段，数据安全合规、技术监管标准、产业
扶持政策、市场准入规则等相关制度仍处于持续完善过程中。若后续行业监管要求
趋严、扶持政策落地进度慢于预期，或合规要求抬升导致企业研发与运营成本增加，
可能对大模型技术迭代、商业化落地及行业竞争格局形成阶段性扰动，行业发展节
奏存在相应调整的可能性。
