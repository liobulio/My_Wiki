# Factor investing

> **Stub** — created as the parent concept for [[momentum-factor]]. Expand as sources arrive.

## Definition
Building portfolios around systematic, persistent return drivers ("factors") rather than
individual security selection. Classic factors: value, [[momentum-factor|momentum]], size,
quality, low-volatility, carry.
