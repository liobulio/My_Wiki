# Portfolio Overview

Live dashboard. The tables below are generated by **Dataview** from `wiki/positions/` —
they update themselves when positions change. (Enable the Dataview community plugin in
Obsidian: Settings → Community plugins → Browse → "Dataview".)

## Open & watched positions

```dataview
TABLE
  ticker AS Ticker,
  weight + "%" AS Weight,
  conviction AS Conv,
  status AS Status,
  thesis AS Thesis,
  updated AS Updated
FROM "wiki/positions"
WHERE status != "closed"
SORT weight DESC
```

## By conviction

```dataview
TABLE rows.ticker AS Tickers, length(rows) AS Count
FROM "wiki/positions"
WHERE status = "open"
GROUP BY conviction AS "Conviction"
SORT conviction DESC
```

## Active theses

```dataview
TABLE asset AS Asset, stance AS Stance, conviction AS Conv, status AS Status
FROM "wiki/theses"
WHERE status = "active"
SORT conviction DESC
```
