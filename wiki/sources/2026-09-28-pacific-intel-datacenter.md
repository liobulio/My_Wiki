# 太平洋证券：Intel Q2 FY2026 点评（2026-09-28）

## TL;DR
太平洋电子团队（张世杰）点评 [[intc|英特尔]] 2026 财年 Q2：收入 **$161.3 亿（+25.4% YoY）**、毛利率 **40.4%（+12.9pct）**。核心亮点是**数据中心与 AI 事业部（DCAI）营收 $62.6 亿（占 38.8%、同比 +59.0%）**，增长来自云厂商 AI 服务器 CPU 及配套 ASIC 订单放量。数据中心需求侧硬数据，间接背书本仓 AI 用电需求。维持「看好」。

## Key takeaways
- **总收入 $16.13B / +25.4%**，毛利率 40.4%（+12.9pct）；Non-GAAP 毛利率同比明显上行，核心是高附加值数据中心芯片占比抬升。
- **DCAI $6.26B / +59.0%**（占 38.8%）：云厂商 AI 服务器 CPU + 配套 ASIC 订单放量——超大规模云 AI 建设直接拉动。
- 客户端计算与物理 AI（CCPG）$88.8 亿 / +12.8%（占 55.0%）：AI-PC 带动商用笔记本修复，消费 PC 复苏偏弱。
- 代工业务（内部抵消前）$57.7 亿、外部客户 +30.5% 但规模仍小，18A 工艺推进、板块仍亏损。
- Q3 FY26 指引：营收 $158–168 亿（中枢 $163 亿）、Non-GAAP 毛利率约 42.0%、Non-GAAP EPS $0.38；下半年判断"服务器算力需求仍具韧性"，客户端 PC 复苏节奏不确定。

## Notable claims
- 「英特尔 2026 财年 Q2 收入 161.3 亿美元，同比增长 25.4%；毛利率 40.4%，同比提升 12.9pct。」
- 「数据中心与 AI 事业部（DCAI）营收 62.6 亿美元，占总营收 38.8%，同比大增 59.0%，本季增长主要来自云厂商 AI 服务器 CPU 以及配套 ASIC 芯片订单放量。」

## Entities mentioned
[[intc]] · 数据中心 / AI 服务器 CPU / ASIC · [[ai-power-demand]]（需求侧算力）· 18A 工艺 / 代工。

## Agrees / contradicts
- **背书需求侧 [[ai-power-demand]]**：DCAI +59%、明确"云厂商 AI 服务器 CPU + ASIC 订单放量"——超大规模云 AI 建设未退坡，与 [[2026-09-26-pacific-amd-datacenter|AMD 数据中心 +107%]]、[[2026-09-29-soochow-overseas-compute-alibaba-20gw|东吴阿里 20GW 蓝图]]同向；间接支持本仓 [[ai-power-ipp-bull|firm 电力稀缺]]需求侧。
- 属**回顾性景气实证**（该季截至 2026-06-27、7 月末已披露），太平洋 09-28 批量补点评；非新增前瞻信息、非本 wiki 买入机会（Intel 非组合标的）。

## Fact-check / Data gaps
- ✅ **DCAI $6.3B / +59% / 总收入 $16.1B / +25.4%**：与 Intel Q2 FY2026（截至 2026-06-27）新闻稿及 10-Q 一致——DCD/Futurum/Motley Fool 均记 DCAI +59%、总收入 $16.1B、"fastest YoY growth since 2011"；DCAI 增长由 hyperscaler server 需求 + server ASP +48% 驱动，DCAI 经营利润率 16.1%→39.5%。太平洋列 $62.6 亿 ≈ 官方 $6.3B、毛利率 40.4% 属 GAAP 口径。
- Q3 指引为公司前瞻，记录、非可核验事实。
