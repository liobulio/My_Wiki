# 太平洋证券：Teradyne Q2 2026 点评（2026-09-28）

## TL;DR
太平洋电子团队（张世杰）点评 [[ter|泰瑞达]] 单季：收入 **$13.3 亿（+103.9% YoY）**、毛利率 **59.8%（+2.6pct）**、稀释 EPS **$2.4**。半导体测试业务 $11.2 亿（占 84.4%、+128.1%）为主引擎——AI 算力带动高性能 SoC 测试需求、DRAM 测试持续强劲、NAND 测试复苏。ATE 侧 AI/存储需求硬数据。

## Key takeaways
- **总收入 $1.33B / +103.9%**，毛利率 59.8%（+2.6pct），第二个连续单季收入新高、超指引上限。
- **半导体测试 $11.2 亿 / +128.1%**（占 84.4%）：AI 算力→高性能 SoC 测试设备高景气 + DRAM 测试强劲 + NAND 存储测试复苏。
- 产品测试 $1.1 亿 / +26.1%（无线/航天防务稳健）；机器人 $1.00 亿 / +33.5%（协作机器人温和修复、工业 capex 回暖滞后、拖累毛利）。
- 逻辑主线：HBM 配套存储测试订单放量承接存储 capex 复苏；机器人聚焦物理 AI 高附加值场景 + 收购整合无线宽带测试打造第二曲线。
- Q3 FY26 指引：营收 $12.0–13.0 亿、Non-GAAP EPS $1.85–2.15（行业属性致环比波动、不改高景气）。

## Notable claims
- 「公司单季度实现营业收入 13.3 亿美元，同比增长 103.9%；毛利率 59.8%，稀释每股收益 2.4 美元。」
- 「半导体测试业务营收 11.2 亿美元，占总营收 84.4%，同比增长 128.1%……受益于 AI 算力带动下高性能 SoC 测试设备需求高景气，同时 DRAM 测试持续强劲、NAND 存储测试需求迎来复苏。」

## Entities mentioned
[[ter]] · SoC / DRAM / NAND 测试 · HBM · [[ai-power-demand]]（需求侧算力）· 协作机器人 / 物理 AI。

## Agrees / contradicts
- **背书 AI 算力 + 存储 capex 复苏**：SoC 测试 +128%、NAND 测试复苏——与 [[2026-09-22-pacific-electronics-ai-memory|AMAT HBM 设备放量]]、[[mu-sndk-memory-upcycle-2026-09|存储上行周期]]同向，属上游设备侧实证；间接支持 AI 建设未退坡（[[ai-power-ipp-bull]]需求侧）。
- 属**回顾性景气实证**（该季截至 2026-06-28、7 月末已披露），非新增前瞻、非本 wiki 买入机会（Teradyne 非组合标的）。

## Fact-check / Data gaps
- ✅ **$1.33B / +104% / 半导体测试 +128%**：与 Teradyne Q2 2026（截至 2026-06-28）新闻稿及 8-K 一致——官方记 $1,329M / +104%、半导体测试 $1,122M / +128%（DRAM 强劲 + NAND final test 复苏）、盈利同比 +300%+、第二个连续收入新高、超指引上限。毛利率/EPS 量级一致。
- Q3 指引为公司前瞻，记录、非可核验事实。
