# 华鑫证券·英伟达 FY27Q2 点评（Rubin 全面量产）

## TL;DR
华鑫维持英伟达"推荐"，复盘 FY27Q2（截至 2026-07-26）：营收 **$962.21 亿**（+106% YoY、+18% QoQ）、GAAP 净利 $596.88 亿（+126%）、非 GAAP 摊薄 EPS $2.22（+120%）。**数据中心 $890 亿（+117%）、占比约 92.5%**，GAAP 毛利率 75.0%、营业利润率约 66.2%。Vera Rubin 平台进入全面量产，机架已在 CoreWeave / 谷歌云 / Azure / Oracle / Nebius 运行；Q3 指引 **$1080 亿**（中值环比 +12.2%，未计入中国数据中心收入）。

## Key takeaways
- **数据中心**：$890 亿、+117% YoY / +18% QoQ、占总收入约 92.5%——AI 基础设施需求继续主导。边缘计算 $72 亿（+27%）。
- **盈利**：GAAP 毛利率 75.0%（+2.6pct）、营业费用 $84.08 亿（+55%，低于收入增速）、GAAP 营业利润 $637.34 亿（+124%）、营业利润率约 66.2%（+5.4pct）——规模效应带动经营利润提升。
- **Rubin 量产**：Vera Rubin 全面量产，多家云部署；配套 Spectrum-6 交换、可插拔光模块/CPO；面向推理的 Groq 3 LPX 也已全面量产。
- **指引**：Q3 营收 $1080 亿 ±2%（中值环比 +12.2%，未含中国 DC 收入）；Q3 GAAP/非 GAAP 毛利率均约 74.0%。

## Notable claims
- "公司 Q2 数据中心收入 890 亿美元，同比增长 117%……占总收入约 92.5%。"
- "Vera Rubin 平台正进入全面量产，机架已在 CoreWeave、谷歌云、微软 Azure、Oracle 云基础设施及 Nebius 等合作伙伴处运行。"
- "预计 Q3 营收 1080 亿美元……未计入来自中国的数据中心计算收入。"
