# 存储新周期：MU / SNDK

## Thesis Test (proposed)
> 由我根据来源起草的**提案**，不是你的观点；采纳前请用自己的话回答三问（CLAUDE.md §3.8）。

- **Edge** — 市场仍按历次消费电子周期给存储股定价：涨价 → 扩产 → 暴跌。但本轮供给弹性被 2022–23 减产与 HBM 对通用 DRAM 产能的挤出压住，需求来自 AI 基础设施的结构性增量而非库存补货，周期应更长、幅度更高。
- **Catalyst** — 美光 FY26Q4 财报（预计 2026-09 下旬）：若 DRAM/NAND 合约价再度环比上涨、管理层重申供给紧张到 2027 之后；叠加云厂商三季报 capex 指引维持或上修。
- **Invalidation** — DRAM 或 NAND 合约价出现环比下跌；任一原厂（三星/海力士/美光）宣布大幅扩产或制程迁移提前；或超大规模云厂商下修 capex 指引。任一出现即提案失效。（东吴列出的风险：capex 不及预期、供给释放快于预期、涨价抑制需求、出口管制。）

## Logic
东吴证券的框架：存储是"需求波动 + 供给滞后"的强周期行业，历次出清后集中度上升、供给纪律增强。本轮叠加
（1）2022–23 原厂减产与 capex 收缩压低供给弹性；（2）HBM 的高晶圆消耗与先进封装约束挤占通用 DRAM 供给；
（3）AI 训练+推理拉动 HBM / 服务器 DDR5 / 企业级 SSD。验证点：美光 FY26Q3 DRAM/NAND ASP 环比 +~60% / +~85%（✅ 已核实）。

## What would kill it
- AI 数据中心 capex 不及预期（[[2026-09-11-apollo-daily-spark-ai-roi|Apollo 的 ROI 质疑]] 是这一风险的前哨）；
- 原厂扩产 / 制程迁移让供给释放快于预期；价格快涨反噬终端需求；出口管制。
